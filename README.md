# AI/ML Learning Academy

A complete, hands-on curriculum from Python fundamentals to production AI systems: 150 topic files in
9 modules, each with theory, a working example and three exercises, plus a local tracker that records
your progress.

| # | Module | Topics | What you'll be able to do |
|---|---|---|---|
| 01 | Python | 54 | Write, debug, test and package Python programs, including async code, APIs, Git and environments |
| 02 | Mathematics | 13 | Linear algebra, calculus and probability, each taught alongside the ML topic that uses it |
| 03 | Data Science | 9 | NumPy, pandas, visualisation, EDA and SQL |
| 04 | Machine Learning | 13 | Train, evaluate, tune and interpret classical ML models |
| 05 | Deep Learning | 10 | Neural networks from scratch, PyTorch, CNNs, embeddings, attention and a tiny GPT |
| 06 | Prompt Engineering | 31 | LLM fundamentals, prompting techniques, evaluation, safety and 8 projects |
| 07 | Generative AI | 5 | Streaming, tool use, embeddings, vector search and LoRA fine-tuning |
| 08 | RAG and Agents | 8 | Retrieval pipelines, RAG evaluation, agents, memory and MCP |
| 09 | MLOps | 7 | Deployment, experiment tracking, CI/CD, monitoring, debugging and the capstone |

The full topic list with links is in [COURSE-MAP.md](COURSE-MAP.md), and your progress is in
[PROGRESS.md](PROGRESS.md). Both files are generated by the tracker.

## Setup

The course has its own virtual environment in `.venv` with NumPy, pandas, matplotlib, scikit-learn,
PyTorch, Pydantic, pytest, FastAPI, httpx and the Anthropic SDK installed.

```bash
cd ~/Desktop/learning/AI-ML-Course
source .venv/bin/activate          # or run files with .venv/bin/python
python 01-Python/01-Variables/01-basics.py
```

To recreate the environment: `uv venv .venv && uv pip install --python .venv/bin/python -r requirements.txt`.
In VS Code, run **Python: Select Interpreter** and choose `AI-ML-Course/.venv`.

## How each topic file works

Every file follows the same structure, written as comments around runnable code:

1. Topic introduction
2. Short theory
3. Real-world analogy
4. Python syntax
5. A small working example (real code that runs)
6. Line-by-line explanation of the example
7. Common mistakes
8. Beginner exercise, 9. Intermediate exercise, 10. Advanced exercise
11. A `# YOUR CODE:` area under each exercise for your solution

Run the file to see the example, read the explanation, then solve the exercises one at a time and ask
your tutor (Claude) to review each solution before moving on.

## Learning tracker

```bash
python3 00-Tracker/server.py            # opens http://127.0.0.1:8765 in your browser
```

- **Dashboard:** overall completion, modules, completed / in-progress / remaining topics, a progress bar
  for each module and section, the status of every exercise, your current position and the next
  recommended topic.
- **Click any topic title** to open that exact file in VS Code. The server runs `code --reuse-window --goto <file>:<line>`.
  If that fails, the link falls back to a `vscode://file/...` URL. Set `TRACKER_EDITOR=cursor` (or
  `windsurf`, `codium`) to use another editor.
- **Completion rules:** a topic is complete only when all five requirements are done: Theory, Beginner,
  Intermediate, Advanced and the final Assessment. Opening a file never completes anything. An exercise
  can be marked done only after code exists under its `# YOUR CODE:` line. The Assessment unlocks after
  the other four: ask Claude to assess you on the topic, then mark it.
- **Sync:** the folders are the source of truth. The dashboard rescans every few seconds. New topic
  files appear on their own, and renamed or moved files keep their progress (matched by the `# ID:`
  header). Deleted files are flagged as missing, with their progress kept until you restore the file or
  choose "Forget entry".
- **Persistence:** everything is saved immediately to `00-Tracker/progress.json`, which survives
  restarts. A corrupted file is reported, never overwritten.
- **Learning order:** `00-Tracker/learning-path.json` interleaves the maths topics with the ML topics
  that use them. The "Learning path" view and the next recommendation follow this order.

Command-line equivalents:

```bash
python3 00-Tracker/server.py status
python3 00-Tracker/server.py sync           # rescan + regenerate PROGRESS.md and COURSE-MAP.md
python3 00-Tracker/server.py check-links    # verify every topic opens in the editor
python3 00-Tracker/server.py open python.variables.basics --exercise beginner
python3 00-Tracker/server.py mark python.variables.basics theory   # add --undo to clear
python3 -m unittest 00-Tracker/test_tracker.py
```

### Adding a topic

Create a numbered file such as `01-Python/05-Loops/04-nested-loops.py` that uses the same header with a
unique ID:

```python
# ======================================
# TOPIC: NESTED LOOPS
# LEVEL: BEGINNER
# ID: python.loops.nested-loops
# ======================================
```

Keep the three `# QUESTION n: BEGINNER|INTERMEDIATE|ADVANCED` blocks, each followed by `# YOUR CODE:`.
The tracker picks the file up automatically. Add it to `learning-path.json` only if it belongs
somewhere other than its folder position.

## Using a real LLM in the Prompt Engineering modules

Examples run offline by default and print clearly labelled sample responses. To call Claude:

```bash
export ANTHROPIC_API_KEY=...      # or: ant auth login
export COURSE_USE_LLM=1
python 06-Prompt-Engineering/02-Prompting-Foundations/01-anatomy-of-a-prompt.py
```

The helper is `06-Prompt-Engineering/course_llm.py`. It uses `claude-opus-5-5` by default (override it
with `COURSE_LLM_MODEL`) and enables server-side refusal fallbacks. Real calls cost money, so watch the
token counts the examples print.
